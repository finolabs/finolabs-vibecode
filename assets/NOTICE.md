A hand-authored check mark between code brackets: code that is verified before it is accepted. Rounded 9-unit strokes follow the FINOLABS icon family, with violet (#9750C4) for light surfaces and mint (#7FE2CE) for dark surfaces. Both themes share identical geometry on a transparent 128-unit canvas. No third-party artwork, font, bitmap tracing or image-model output is included.

Editable sources are icon.svg and icon-dark.svg. The two PNG files are transparent 512×512 exports rendered from them with a browser canvas.
