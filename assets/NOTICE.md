# Finolabs Vibecode icon

Copyright (c) 2026 Fioenix / FINOLABS. Distributed under the project MIT license.

The owner approved this hand-authored text-emoji: a winking robot face between code brackets, written as `<■ ->`. The filled square is the open eye; the dash is the winking eye. Rounded 9-unit strokes follow the FINOLABS icon family, with violet (#9750C4) for light surfaces and mint (#7FE2CE) for dark surfaces. Both themes share identical geometry on a transparent 128-unit canvas. No third-party artwork, font, bitmap tracing or image-model output is included.

Editable sources are icon.svg and icon-dark.svg. The two PNG files are transparent 512×512 exports rendered from them with a browser canvas.
