Away from keyboard: what afk does while you are gone

Start afk once; every session on the machine checks each action against the lease and the repository's own rules, does only what is allowed, parks the rest for you, settles questions on a ladder and asks you to review each decision when you are back. This page shows strict; in open, the default, every action runs except the credential floor and two guards (third-party instructions grant nothing; the default branch is protected).
