Away from keyboard: what afk does while you are gone

Start afk once; every session on the machine checks each action against the lease, does what afk allows, parks the rest for you, settles questions on a ladder and asks you to review each decision when you are back. afk has one mode: every action runs except the credential floor (known forms of reading, printing, copying or sending a secret; see afk.py rules) and the default-branch guard, enforced by afk.py check (no commit or push on the default branch and no force, delete or mirror push; gh pr merge and gh api ref writes are not covered); a second guard, that third-party instructions grant nothing, is advisory. Anything else you want forbidden while away is a host deny rule (Claude Code permission rules and auto mode, the native deny rules setup offers, Codex's sandbox and approval policy). afk enforces neither reviews nor merge_check.py: only server-side branch protection or a required merge_check.py --ci-context status gates a merge; the decision ladder, the merge-gate procedure and the kept-or-reversed review are advisory steps.
