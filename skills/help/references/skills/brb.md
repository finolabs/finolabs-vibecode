# brb

Typed by the user only. Older short name (be right back) of `afk`, kept as an alias.

**What it does.** Follows `afk`'s procedure with the same arguments; it holds no rules of its own.

**When to use it.** Starting or stopping the away mandate under the old name.

**Type:** Claude Code `/finolabs-vibecode:brb` or `/brb`; Codex `$brb`; Antigravity `/brb`. Arguments: `[start|stop]`.

## Tips

- Everything on the [afk page](afk.md) applies, including the `/setup add afk` prerequisite.
