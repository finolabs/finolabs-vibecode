# gtg

Typed by the user only. Short name (got to go) of `pause`.

**What it does.** Follows `pause`'s procedure with the same arguments; it holds no rules of its own.

**When to use it.** Before a restart or shutdown, when the short name is quicker to type.

**Type:** Claude Code `/finolabs-vibecode:gtg` or `/gtg`; Codex `$gtg`; Antigravity `/gtg`. Arguments: `[restart|shutdown] [--in <minutes>] | status | resume`.

## Tips

- Everything on the [pause page](pause.md) applies.
