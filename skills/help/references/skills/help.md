# help

Typed by the user only.

**What it does.** Answers questions about this plugin in plain words: where to start, what it contains, how a skill, agent or script works, and which skill fits your situation, with the command to type next. It answers and stops; it invokes nothing and does not ask another agent for an opinion.

**When to use it.** You are new and do not know where to start, want to know what the plugin holds, or have a question about one piece of it.

**Type:** Claude Code `/finolabs-vibecode:help` (the plain `/help` opens Claude Code's own help); Codex `$help`; Antigravity `/help`. `ask` is its older name.

## Tips

- Say what you want: "where do I start" (Start), "what is in it" (Contents), "how does `afk` work" (Explain), or describe your situation (Route).
- It answers in the language you write in and keeps command and skill names unchanged.
- New to coding? It gives only the next step and what comes after it.
