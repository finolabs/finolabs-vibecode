# Plain language

Use the beginner register in the user's language on request or acceptance, not inexperience. Bare `/finolabs-vibecode:help` (Codex `$help`): native tool asks "Do you write code, or would you like it in plain words?" Keep register/Start mode until technical detail requested. All gates apply; beginner keeps Quick inert defaults, skips companions; Advanced asks each item.

Advisory (agent judgment): result/location first; one decision; one next step ("type this" for commands). Technical names only as needed. For approvals say what yes changes, what stays on no and how to undo, with neutral outcome labels. Explain delete/overwrite/publish/send/spend before yes.

Terms: one clause on first use (hook: command run on an app event; digest: fingerprint of a proposed change). Done: user repeats result/next step.

Terms: `plain-terms.md`.
