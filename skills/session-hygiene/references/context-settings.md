# Context settings

**Native settings.** Read from each host's documentation and installed binary on 2026-11-05; the host enforces them, and no value is prescribed because the right one is the user's choice:

- Claude Code (documented, code.claude.com): `autoCompactWindow` in settings (100000 to 1000000 tokens), `/autocompact <tokens>` (saved per model) and the `--autocompact` flag; the `CLAUDE_CODE_AUTO_COMPACT_WINDOW` variable overrides all three, so a valid value set there makes the others do nothing; `CLAUDE_AUTOCOMPACT_PCT_OVERRIDE` only lowers the trigger; `autoCompactEnabled` and the `DISABLE_AUTO_COMPACT` variable turn it off. Models with a native 1M window compact late by default (about 967K tokens per the documentation), so for them the advisory 60% is far earlier than the host's trigger; models on extended context compact at the context limit.
- Codex 0.166.0 (config reference and binary; defaults unverified on this version): `model_auto_compact_token_limit`, `model_post_turn_compact_threshold_percent` (0 or unset disables only this turn-end trigger; other auto-compaction limits still apply), and background compaction under `[features] async_compaction`.
- Antigravity 1.5.3 (installed version at research time; vendor docs and release notes, 07/11/2026): compacts automatically; no threshold or off switch is documented. `/context` shows usage; `/clear`, `/new`, `/fork` and `/rewind` manage context. `/compact` was not found in the docs and may not exist; offer `/new` or `/fork` instead (advisory, agent judgment). The reported `AGY_CLI_AUTO_COMPACT_OVERRIDE` and `compactionThreshold` remain unverified and are never suggested (advisory, agent judgment).

The agent rechecks the installed host's documentation or help before suggesting a setting, since names and defaults change; this is advisory (agent judgment). `/setup` offers guidance only after the user's yes. `setup` writes only the one documented key (`autoCompactWindow` or `model_auto_compact_token_limit`) after the user chose a value and said yes to a previewed plan; it never sets environment variables or the percent override. Enforcers: the setup script checks the plan and write; asking is advisory (agent judgment); the host enforces the threshold.

**Antigravity compaction stop (opt-in).** `setup` offers separate consent and a preview for a user-chosen limit of 50000 to 20000000 transcript bytes; asking and showing the preview are advisory (agent judgment). The installer enforces the stored digest, 60-minute expiry and safe files. Enforcer: `compact_stop_hook.py`, in its own user-configured group, acts only on `PreInvocation` at `invocationNum` 0, before that model invocation. Whether 0 marks the first call of each user turn remains unverified; vendor docs describe a 0-indexed counter without documenting its reset.
It measures only the size of a regular non-symlink transcript in the account's conversation folder and writes a private integer mark before stopping. It stops again only after both 10% and 20000 bytes of growth, resets on shrink, and allows on errors. It never denies tools or the user's stop, reads transcript content, sends data or runs `/compact`. The byte proxy excludes the system prompt; there is no recommended default. `FNL_COMPACT_STOP=off` disables it; setup's previewed `--remove` removes its group and records `Enabled: no`.
Antigravity [hooks docs](https://antigravity.google/docs/hooks), researched 07/11/2026 through 1.5.3, confirm user hooks at `~/.gemini/config/hooks.json`; `~/.gemini/antigravity-cli/settings.json` is not loaded for hooks. Live user-level delivery and the TUI remain unverified; workspace `agy -p` output was verified on 1.5.1 on 06/11/2026. The fixed script message still asks for `/compact`; that command may not exist, so offer `/new` or `/fork` (advisory, agent judgment). Changing the fixed message needs an owner decision.

**Compaction nudge.** On Claude Code a `UserPromptSubmit` hook (`compact_nudge.py`) reads only the latest turn's token counts and the compaction settings, and at 80% and again at 90% of the threshold prints one line telling the agent to run this skill now: save the handover, write back decisions and lessons, note background runs and open pull requests, then offer to compact or start a fresh session (acting on it is agent judgment). With auto-compaction off or no window set it prints nothing; `FNL_COMPACT_NUDGE=off` disables it. Codex and Antigravity have no nudge.

**PreCompact hook.** Claude Code and Codex declare `PreCompact`; `precompact.py` prints constant summary instructions: keep the goal and acceptance criteria, settled decisions with dates, work in progress, open runs and pull requests, the next action and whether a handover was saved. It runs after compaction has started, so the agent cannot write a handover then. No network or metrics, exit 0 with exceptions silenced, never blocks compaction. Antigravity has no `PreCompact` declaration.
Vendor docs and pinned Codex source, researched 07/11/2026: Claude Code [hooks](https://code.claude.com/docs/en/hooks.md) use PreCompact stdout as summary instructions (up to 10,000 characters), not documented as added to model context. Codex 0.167.0 [hooks](https://learn.chatgpt.com/docs/hooks) and `rust-v0.167.0` source ignore plain stdout from PreCompact and PostCompact: **on Codex a plain-text reminder does not reach the model**. Write the handover on `prepare`, before compaction (advisory, agent judgment).
SessionStart with `source: compact` is the documented delivery path on both hosts: Claude Code [context-window docs](https://code.claude.com/docs/en/context-window.md) add stdout to model context; Codex 0.167.0 delivers plain stdout or JSON `additionalContext` as developer context before the next model request. Claude PostCompact receives `trigger` and `compact_summary`. Live delivery/order of this plugin's handover remains unverified; Check reports file evidence separately (advisory, agent judgment).
