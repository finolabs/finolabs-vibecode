# Decisions in a spec or plan

Detail behind `SKILL.md` "4. Work, then gate". Read it when you write or update a spec or plan. Enforcer: agent judgment, advisory.

A spec or plan asks the user the decisions the user can settle, through the host's native question tool when the session has one (text otherwise), the recommended option first, and records the answers in the document as settled decisions with the date.

Only a decision the user cannot make yet (it needs evidence, another person or a later step) stays listed as open, with its owner and what unblocks it.

A delegated or headless run with nobody to answer records its decisions as open and never invents an answer.
