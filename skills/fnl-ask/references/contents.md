# Contents

The user asks what is in the plugin, or what exists for a purpose. Read [map.md](map.md) and list the skills, agents and scripts grouped by purpose, in three groups: typed by the user only (`fnl-setup`, `fnl-setup-instructions`, `fnl-status`, `fnl-ask`); typed by the user or loaded by the agent (`fnl-handoff`, loaded directly by `fnl-delegate`; `fnl-advisor` and `fnl-committee`, proposed first and waiting for the user's yes); and loaded by the agent when the task matches (the rest). When the installed folder differs from the map, trust the folder: list the `fnl-` skills beside this one and the plugin root's `agents/fnl-*.md` with each file's one-line description, and fall back to the map when neither can be listed. State a count only after counting it in the folder; when the folder cannot be listed, say the list comes from the map and give no totals.
