# Plain language

Use the user's language and beginner register on request/acceptance, not inexperience. Bare `/fnl-ask` (Codex `$fnl-ask`): native tool asks "Do you write code, or would you like it in plain words?" Keep register/Start mode until technical detail requested. All gates apply; beginner keeps Quick inert defaults, skips companions; Advanced asks each item.

Advisory (agent judgment): result/location first; one decision; one next step ("type this" for commands). Technical names only as needed. Mirror interview.md's approval shape: short goal/effect question; Yes: change, file/setting/location, data leaving; No: unchanged items, off/declined writes, answer later; Undo: reversal. Neutral outcome labels ("Yes, record it" / "No, leave it off"), none preselected/recommended; option descriptions match. Explain delete/overwrite/publish/send/spend before yes.

Explain terms in a clause on first use (hook: command run on an app event; digest: fingerprint of a proposed change). Examples; detail on request. Done: user repeats result/next step.

Term translations: `plain-terms.md`, when needed.
