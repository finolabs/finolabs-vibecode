Dependency: `autopilot`. `autopilot` is user-only (`disable-model-invocation: true`), so the Skill tool refuses it: read `autopilot`'s `SKILL.md` in this plugin's skills folder and follow it with the same arguments; never call the Skill tool for it (advisory (agent judgment)).
This alias holds no rules of its own.
