## Where files go

Shared files (documentation and design notes with lasting value) go in the project's documentation folders and are committed. Local files go in `.finolabs/`, kept out of git through `.git/info/exclude` (the shared `.gitignore` changes only with the user's approval); never in temporary directories or session scratchpads. A repository that still has the older `.orchestration/` folder and no `.finolabs/` keeps using it; nothing is moved for the user. The full rule: [references/dispatch.md](dispatch.md) "Where files go".

- **Briefs, notes and captured state**: `.finolabs/briefs/` at the main checkout's root (`git rev-parse --path-format=absolute --git-common-dir`, then its parent).
- **Run logs and outputs**: `.finolabs/logs/` of the task checkout, the checkout the run works in. Run the headless form and its `ledger.py finish`, scan, show and redact from that checkout. `ledger.py finish --log-path` also accepts a log directly in `.finolabs/logs/` of the `--checkout` checkout or of the main checkout, so a coordinator in another worktree can close the run; `log_scan.py scan`, `show` and `redact` read only the current checkout's folder. Host-config paths do not widen the log guard.
