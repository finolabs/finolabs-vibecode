# Interview rules

Advisory (agent judgment): map decisions/dependencies; ready means prerequisites settled. Look up authorized facts first; ask decisions or failed lookups, citing failure. Ask all ready decisions per round, numbered with recommendation/reason; update after answers.

Use native question tool (AskUserQuestion/request_user_input/ask_question); preferences recommended first, Other for free text, respect limits, blocking first. Read-back/consent: neutral Yes and No, no preselection/recommendation; timeout/default is never yes.

Text fallback: tool absent/refused/failed, nobody can answer, or free text (model IDs). Headless: record open decisions, invent nothing. Clarify vague answers. Finish with no silent assumptions; read back, get yes before writes. Installed grilling may interview under these rules.
