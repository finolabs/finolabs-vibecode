# Interview rules

Questions: advisory (agent judgment). Ready: prerequisites settled. Look up authorized facts first; ask decisions/failed lookups, citing failure. Ask all ready decisions per round; number them; update after answers.
Ask every question through the host's native question tool when the session has one (AskUserQuestion/request_user_input/ask_question). Preferences: recommendation/reason first; Other for free text; respect tool limits, blocking first.
Offer neutral Yes and No choices with none preselected or marked recommended; a default, a timeout or an auto-selected option never counts as the yes. All approvals/offers, every mode.

Approval shape: short goal/effect sentence, no internal subject; explain technical terms in a clause at first use. Translate question/description/labels. Show the local block in order:
Yes: change, file/setting, location, data leaving.
No: unchanged items, any off/declined write, answer later.
Undo: reversal or nothing changed.
Choices: outcome labels ("Yes, record it" / "No, leave it off"), neutral; native option descriptions match. For removal describe its inverse. Preferences/free text keep their choices; blocks explain later approval. Read-backs: inert notes only. Implementation text: agent-only.

Ask in text only with no tool, when the tool is refused or fails, nobody can answer, or for free text. Headless: record open, invent nothing. Clarify; read back, explicit yes before writes. Grilling: same rules. Companions: none preselected; "install everything" grants nothing; Yes prints only, never installs/stores consent.
