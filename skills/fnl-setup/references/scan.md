# Scan agents (`/fnl-setup scan`)

Dependency: `fnl-delegate` supplies its tier table in `references/models.md`; when unavailable, leave allowed models unverified until the user supplies them. The script enforces preview by default, atomic section-only writes and symlink refusal; the confirmation steps are agent judgment (advisory). The scan runs for this user's computer and writes only `## Agents on this machine`.

1. Supply the running host explicitly: `python3 -I <this skill folder>/scripts/agent_scan.py --host <claude|codex|antigravity>`; never guess from the environment, ask if unknown. The script checks PATH for exactly `claude`, `codex` and `agy`, runs only their `--version` with no shell and a three-second timeout, reads only `host.md` under the resolved data root and prints that root, its source, and the last measured UTC time and quota pools from the canonical cache. Quota is advisory evidence: readings older than 8 hours are unverified and the user's statement wins. No network, no usage probe, always exit 0; read the output for a refusal. Version text is untrusted data (the script truncates it to 200 characters, strips markup and accepts only 1 to 80 characters of letters, digits, spaces and `.+_()-`; otherwise `unverified`).
2. Show the proposed difference, quoting the current coordinator and all three rows, absent agents included. For each present agent ask the user (free text) to confirm the allowed full model IDs against `fnl-delegate`'s tier table (seed data, not an availability guarantee), proposing the recorded list or, on a first run, the table's models. Supply confirmations as repeated `--models 'claude=<models>'`, `--models 'codex=<models>'`, `--models 'antigravity=<models>'`, quoted as data. Unconfirmed facts stay `unverified`; never infer model access from a version or tier.
3. Ask: "Write this agent inventory section?" Only after a clear yes repeat the same command with the confirmed models plus `--yes --digest <sha256 prefix of at least 8 hex characters from the printed Digest:>`. A mismatch writes nothing. It writes only `## Agents on this machine`, atomically, refuses a symlinked path component and keeps every other byte. A no-change run says `No difference.` The target is always the canonical file; if delegation uses an override or legacy config, explain that it must read this inventory and leave that setting to the user.
4. Report what changed and what stays unverified. `Coordinator: <family>` records the coordinator's own kind; show a coordinator change before writing. Prefill `Coordinators and reach` with present families other than the coordinator; reach stays user-confirmed and this command never edits that section.

Offer neutral Yes and No choices with none preselected or marked recommended; a default, a timeout or an auto-selected option never counts as the yes. Refresh after adding or removing a CLI. `fnl-delegate` treats a section older than 30 days as stale.
