# Delegation mode and Routing (`/fnl-setup mode`)

The script enforces preview by default, atomic writes and symlink refusal; the user's clear yes is agent judgment (advisory). No network or model call. `fnl-delegate` explains the rules (its mode section, when installed); if absent, say manual is a user-requested handoff, suggest asks first and auto is guideline-led handoff of independent tasks with clear tests. Safety gates and authority are unchanged; auto is never 100%.

1. With no arguments run `python3 -I <this skill folder>/scripts/mode.py show` and report effective Delegation mode, Routing and Auto gate with their sources: `FNL_DELEGATION_MODE` / `FNL_ROUTING`, host config, or default (`suggest` / `on` / `off`). Environment values win and invalid ones use defaults; when `show` reports an override, say the file write has no effect while it stays set. Auto gate is on only by `## Auto gate` `on` in host config; `FNL_AUTO_GATE` `off`, `0`, `false`, `no` override it to off and no environment value enables it. Change no environment or shared setting.
2. Ask the preferences question (also on the beginner path): "How should I hand work to other AI helpers: manual, suggest, or auto; and should the coding guideline start automatically: on or off?" Default when not chosen: suggest and on. Offer `manual` and `suggest` here; `auto` has its own question: "Arm auto delegation, where the coordinator hands independent tasks to other agents without asking each time?" Run `mode.py set --delegation-mode <m> --routing <on|off>` without `--yes`, with only the requested flags, show old and proposed values and any override, and ask for a clear yes to the shown change. Routing off removes this pack's session-start reminder on supported hosts; named skills and stronger instructions still apply.
3. Offer `auto-gate on|off` only when the effective mode is `auto`, with `set --auto-gate on|off`. Before the yes explain: the Claude Code hook, where installed, may deny the first file write in a repository with no decision in the last 8 hours; a recorded decision or prior denial allows later writes in that window; it does not cover shell commands and is not an approval or security control. Ask: "Turn the auto gate on?" Turn it off with `/fnl-setup mode auto-gate off` or `FNL_AUTO_GATE=off`, which applies at once. Other hosts use advisory agent judgment.
4. Only after the yes repeat the same `set` with `--yes`. Routing and Auto gate go only to `host.md` under the resolved data root; Delegation mode uses `ORCHESTRATION_HOST_CONFIG` when set, else the same file; legacy files are not used. If the requested settings target different files the script refuses before writing; set Delegation mode in a separate confirmed command. Only the requested `## Delegation mode` / `## Routing` / `## Auto gate` sections change and every symlinked path component is refused. Exit 0 alone does not prove a write: report the result and the effective values from `show`, including any override that still wins. A refusal leaves the change pending; do not bypass it. Offer neutral Yes and No choices with none preselected or marked recommended; a default, a timeout or an auto-selected option never counts as the yes.
